# Tiny Terra

Tiny Terra is a cozy mobile-first idle terrarium game MVP built with Vite + React + TypeScript. Grow moss, mushrooms, plants, and bugs while passively generating Water, Light, Life, and Spores in a magical glass ecosystem.

## Features
- Mobile portrait UI with safe-area padding
- Live terrarium with generated cozy visuals (no external assets)
- Idle progression, actions, research, collection, settings
- LocalStorage save/load + offline progress popup
- Terrarium level progression and object spawning variation

## Setup
```bash
npm install
npm run dev
npm run build
```

## Notes
- No backend required
- Optional rewarded-ad placeholders are present only as UI placeholders
